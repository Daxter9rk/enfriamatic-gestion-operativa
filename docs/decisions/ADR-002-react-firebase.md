# ADR-002: React y Firebase

- Estado: aceptado
- Fecha: 2026-08-06

## Decisión

Usar React 19, TypeScript estricto y Vite en frontend; Firebase modular para Auth preparada,
Firestore, Storage, Functions Gen 2 y Hosting.

## Consecuencia

La solución mantiene un cliente ligero y reserva operaciones sensibles para backend.
