# ADR-005: Construcción vertical por bloques

- Estado: aceptado
- Fecha: 2026-08-06

## Decisión

Implementar una capacidad completa por misión, incluyendo reglas, UI, backend, pruebas y
documentación, sin anticipar módulos futuros.

## Consecuencia

El siguiente bloque será autenticación, perfiles, roles y protección de rutas; no comenzó durante el
bootstrap.
