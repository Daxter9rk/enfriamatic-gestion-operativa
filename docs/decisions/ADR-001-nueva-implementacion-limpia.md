# ADR-001: Nueva implementación limpia

- Estado: aceptado
- Fecha: 2026-08-06

## Decisión

Construir Gestión Operativa desde cero, sin copiar código, configuración, datos, assets ni historial de
V2/V2.1.

## Consecuencia

El arranque requiere más trabajo fundacional, pero elimina dependencias y supuestos heredados no
aprobados.
